# Фронтенд без ИИ-шаблонов (ai-frontend-signs)

Навык для ИИ-агентов (Codex, Claude Code, Cursor, Antigravity) и фронтенд-разработчиков: выявление и устранение безликих шаблонов и «ИИ-слопа» в интерфейсах, лендингах, веб-сервисах и мобильных приложениях.

## Назначение

Навык помогает оценивать предметность, визуальную иерархию и практическую пригодность интерфейса для пользователя, убирая типичные шаблонные дефекты генерации:
- засилье однотипных фиолетовых оттенков без привязки к бренду;
- цветные размытые пятна и градиентные «облака», мешающие чтению текста;
- избыточные круглые подложки у каждой иконки, создающие визуальный шум;
- парящие оторванные от продукта 3D-абстракции;
- одинаковые карточки одинакового размера для элементов разной важности;
- немотивированные bento-сетки ради тренда, ломающие сценарий пользователя;
- бессмысленные общие фразы в заголовках и кнопках вместо понятного действия.

Навык не выносит вердикт о том, кто автор дизайна (человек или нейросеть), а оценивает интерфейс с инженерной и продуктовой точки зрения.

## Два режима работы

1. **Проверить** — аудит интерфейса без изменения исходных файлов проекта (для дизайн-ревью, PR и ответа на вопрос «выглядит ли это как типовой шаблон нейросети?»).
2. **Сделать не ИИ** — исправление подтверждённых шаблонных проблем в рамках порученной задачи разработки frontend без лишнего редизайна и разрушения рабочей структуры.

## Каталог 19 признаков

Каталог включает подробный чек-лист F01–F19 с критериями проблемы и рекомендациями по исправлению:
- Анализ фокусов внимания, контраста и читаемости;
- Сохранение регулярности таблиц, каталогов и рабочих панелей;
- Примеры корректных решений и контрпримеры.

Подробности смотрите в файлах [`references/checklist.md`](references/checklist.md) и [`references/examples.md`](references/examples.md).

## Установка

```sh

# Или каталоги отдельных инструментов:

# ~/.cursor/skills/ai-frontend-signs
# ~/.codex/skills/ai-frontend-signs

```
